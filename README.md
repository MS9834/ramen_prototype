# 새롱분식점 컵라면 게임 (시험판)

휴대폰 브라우저에서 바로 하는 게임입니다. 설치 없이 링크만 누르면 실행됩니다.

## 게임 링크

| 게임 | 링크 |
|---|---|
| 컵라면 만들기 (v3) | https://ms9834.github.io/ramen_prototype/ |
| 새롱분식점 미니게임 (v14) | https://ms9834.github.io/ramen_prototype/snackbar.html |

예전 링크(`version-each.html`, `version-once.html`)로 들어와도 최신 컵라면 만들기 게임이 열립니다.

## 컵라면 만들기 게임 순서

라면 고르기 → 물 붓기 → 3분 기다리기 → 소스 뿌리기 → 비비기 → 결과(별점)

- 처음 하면 단계마다 조작 방법이 잠깐 나옵니다. [튜토리얼 건너뛰기]로 바로 할 수도 있습니다.

## 새롱분식점 미니게임

손님 말풍선에 나온 컵라면 버튼을 빠르게 눌러 주는 60초 게임입니다.

## 참고

- 시험판이라 일부 그림은 임시 그림입니다.
- 소리가 안 나면 휴대폰 무음 모드를 확인해 주세요.
