# 컵라면 만들기 게임 (시험판)

휴대폰 브라우저에서 바로 하는 컵라면 만들기 게임입니다. 설치 없이 링크만 누르면 실행됩니다.

## 게임 링크

| 버전 | 링크 |
|---|---|
| 단계마다 안내 | https://ms9834.github.io/ramen_prototype/version-each.html |
| 처음에 한 번에 | https://ms9834.github.io/ramen_prototype/version-once.html |

두 버전은 튜토리얼(조작 안내)을 보여 주는 방식만 다릅니다.

- **단계마다 안내**: 각 단계가 시작하기 직전에 조작 방법이 잠깐 나옵니다.
- **처음에 한 번에**: 게임 전에 다섯 단계 조작 방법을 넘겨 보며 익힙니다.

## 게임 순서

라면 고르기 → 물 붓기 → 3분 기다리기 → 물 버리기 → 소스 뿌리기 → 섞기 → 시식 → 결과(별점)

## 참고

- 시험판이라 그림은 임시 그림입니다.
- 소리가 안 나면 휴대폰 무음 모드를 확인해 주세요.
